# 🌧️ 03 — VARSHA-AI

### *GeoAI-Powered Precipitation Intelligence & Visualization System for India*

An AI-powered rainfall intelligence platform designed to analyze historical precipitation data and generate future rainfall forecasts.

### 🚀 Features

* 🇮🇳 India-wide rainfall intelligence
* 🗺️ State-wise forecasting
* 📊 Historical rainfall analysis
* 🌧️ Annual rainfall forecasting
* 📅 Monthly & seasonal analysis
* 📈 Interactive Plotly visualizations
* 🛰️ Scientific NetCDF data processing
* 🤖 XGBoost forecasting models

### 📊 Model

**XGBoost**

Training period: `1901–2015`
Testing period: `2016–2025`

**Reported Metrics**

* RMSE: **41.87 mm**
* MAE: **20.61 mm**
* R²: **0.9543**

**Tech:** `Python` `XGBoost` `Pandas` `Xarray` `NetCDF` `Plotly` `GeoAI`
