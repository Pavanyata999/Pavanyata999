# Featured Projects

## 01 — SAR-Based Marine Oil Spill Detection

### Deep Learning for SAR Satellite Imagery

A deep learning-based semantic segmentation system for detecting **marine oil spills from SAR satellite imagery**.

The system works with **Sentinel-1 and ALOS PALSAR** satellite imagery and uses a hybrid deep learning architecture for segmentation.

### Architecture

**SegNet + DeepLabV3+**

### Key Areas

- SAR satellite image processing
- Semantic segmentation
- Deep learning
- Computer vision
- Remote sensing
- Marine oil spill detection

### Reported Results

| Metric | Result |
| :--- | :---: |
| Accuracy | **94.85%** |
| IoU | **0.5685** |
| ROC-AUC | **0.9330** |

### Technologies

`Python` `PyTorch` `SegNet` `DeepLabV3+` `Computer Vision` `SAR` `Remote Sensing`

## 03 — VARSHA-AI

### GeoAI-Powered Precipitation Intelligence and Visualization System for India

An AI-powered rainfall intelligence platform for analyzing historical precipitation data and generating rainfall forecasts across India.

### Key Features

- State-wise rainfall forecasting
- Historical precipitation analysis
- Annual rainfall forecasting
- Monthly rainfall analysis
- Seasonal analysis
- Interactive visualization
- NetCDF scientific data processing
- XGBoost-based forecasting

### Model

**XGBoost**

**Training Period:** 1901–2015  
**Testing Period:** 2016–2025

### Reported Evaluation

| Metric | Result |
| :--- | :---: |
| RMSE | **41.87 mm** |
| MAE | **20.61 mm** |
| R² | **0.9543** |

### Technologies

`Python` `XGBoost` `Pandas` `Xarray` `NetCDF` `Plotly` `GeoAI`
